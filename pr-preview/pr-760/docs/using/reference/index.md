# Reference

[llms.txt](https://crossplane-contrib.github.io/provider-keycloak/pr-preview/pr-760/llms.txt)


Reference pages collect reusable provider concepts that apply across many
resources, such as credentials, ProviderConfig, troubleshooting, and common
Crossplane manifest patterns.

For resource-specific field schemas, use the generated CRDs in `package/crds/`.


  
  - [ProviderConfig](https://crossplane-contrib.github.io/provider-keycloak/pr-preview/pr-760/docs/using/reference/provider-config.md): Connection details and authentication for a Keycloak instance

  
  - [Credentials](https://crossplane-contrib.github.io/provider-keycloak/pr-preview/pr-760/docs/using/reference/credentials.md): All supported credential fields and authentication methods

  
  - [Common Patterns](https://crossplane-contrib.github.io/provider-keycloak/pr-preview/pr-760/docs/using/reference/common-patterns.md): Cross-cutting Crossplane patterns: references, selectors, policies

  
  - [Troubleshooting](https://crossplane-contrib.github.io/provider-keycloak/pr-preview/pr-760/docs/using/reference/troubleshooting.md): Diagnose and resolve common issues
