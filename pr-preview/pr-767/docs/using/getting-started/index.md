# Getting Started

[llms.txt](https://crossplane-contrib.github.io/provider-keycloak/pr-preview/pr-767/llms.txt)


Get provider-keycloak up and running in three steps.


  
  - [Installation](https://crossplane-contrib.github.io/provider-keycloak/pr-preview/pr-767/docs/using/getting-started/installation.md): Add the provider to your Crossplane cluster

  
  - [Configuration](https://crossplane-contrib.github.io/provider-keycloak/pr-preview/pr-767/docs/using/getting-started/configuration.md): Create a ProviderConfig pointing at your Keycloak instance

  
  - [First Realm](https://crossplane-contrib.github.io/provider-keycloak/pr-preview/pr-767/docs/using/getting-started/first-realm.md): Declare a realm, client, and user — then watch them appear in Keycloak
