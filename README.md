`provider-keycloak` is an open-source [Crossplane](https://crossplane.io/)
provider for declaratively managing [Keycloak](https://www.keycloak.org/)
resources. It is generated with [Upjet](https://github.com/crossplane/upjet)
from the [Keycloak Terraform Provider](https://github.com/keycloak/terraform-provider-keycloak).

## Documentation

- [Get started](https://crossplane-contrib.github.io/provider-keycloak/docs/using/getting-started/)
  with installation, configuration, and your first realm.
- Browse the [managed resources](https://crossplane-contrib.github.io/provider-keycloak/docs/using/resources/)
  and their examples.
- Find [ProviderConfig, credentials, common patterns, and troubleshooting](https://crossplane-contrib.github.io/provider-keycloak/docs/using/reference/).
- See the [development guide](https://crossplane-contrib.github.io/provider-keycloak/docs/developing/)
  for building, local development, and testing, including [end-to-end tests](https://crossplane-contrib.github.io/provider-keycloak/docs/developing/e2e-tests/).

The repository's [`examples`](examples/) directory also contains example
manifests. For importing Keycloak built-in objects, see
[function-keycloak-builtin-objects](https://gitlab.com/corewire/images/crossplane/function-keycloak-builtin-objects).
